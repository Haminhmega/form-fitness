# Exercise catalog data

Form includes an on-demand catalog derived from the Kaggle **Gym Exercise Dataset** by Niharika Singh.

- Source: https://www.kaggle.com/datasets/niharika41298/gym-exercise-data
- Dataset version inspected: 2022-12-30
- License declared by Kaggle: CC0 1.0 / Public Domain
- Source rows: 2,918
- Imported unique rows: 2,906 (case-insensitive duplicate titles and seven existing Form movements were omitted)

The catalog is loaded only when the exercise library or routine picker is opened. Catalog movements are labeled **Logging only** and never inherit AI support based on their names. A catalog record is copied into a user's training document only after the user adds it to a routine, which keeps account documents small.

Descriptions are source data, not personalized coaching or medical advice. Form preserves the source category, body-part, equipment, level, and rating fields when available.
